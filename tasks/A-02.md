# A-02 · Departure planning + itinerary builder
**Track:** A · **Level:** L1 · **Estimate:** 90 min · **Branch:** `track-a`
**Depends on:** none (uses `time.ts` helpers from Phase 0)

> Read `CLAUDE.md` first. All times are computed by code. The model later only writes prose from these items.

## Context
`packages/shared/src/logic/itinerary.ts` has stubs `planDeparture(game, settings, constraint, strategy)` and
`buildItinerary({ game, settings, plan, hotel, homeCity })`. Times are naive local strings (`YYYY-MM-DDTHH:MM`); use
helpers in `logic/time.ts` (`combine`, `addMinutes`, `addDays`, `hoursBetween`, `isBefore`, `resolveDay`, `formatDayTime`).

Relevant settings (`data/settings.json`): `avg_bus_mph` 55, `departure_buffer_min` 30, `min_hours_arrival_before_kickoff` 3,
`min_hours_meal_before_kickoff` 3, `latest_hotel_arrival` "23:00". Game fields: `date`, `kickoff_local`, `road_miles_one_way`,
`drive_hours_one_way`, `route_stop_city` ('' if none), `city`, `stadium_name`. Hotel: `name`, `miles_to_stadium`.

`ItineraryItem = { id 'IT-n', kind, label, start_local, end_local ('' if instant), location, meal_id ('' unless meal) }`.
Kinds: depart, stop, meal, arrive_hotel, checkin, walkthrough, meeting, curfew, depart_hotel, arrive_stadium, kickoff,
depart_return, arrive_home. **IDs are assigned after sorting chronologically: IT-1, IT-2, …** (they become the
athlete assistant's fact ids). Meal items get `meal_id` ML-1, ML-2… in order; `location` '' (A-03 fills it).

## Rules (record any deviation in DECISIONS.md)
**Drive time:** `drive_min = ceil5(max(drive_hours_one_way × 60, road_miles_one_way / avg_bus_mph × 60))`, where `ceil5` rounds up to 5 min.
Each leg's arrival = departure + drive_min + stop minutes + `departure_buffer_min` (traffic slack).

**Strategies:** `day_before_afternoon` (Economy, Balanced) default departure = day before at 12:00. `day_before_morning`
(Game-Ready) = day before at 09:00. `game_day` (same-day, only when drive ≤ 2.5 h and kickoff ≥ 15:00) = kickoff −
`min_hours_arrival_before_kickoff` h − drive − buffer.

**Constraint:** `not_before T` → departure = max(default, T). `not_after T` → departure = min(default, T). `none` → default.
**Feasible** unless arrival at the destination city is later than kickoff − `min_hours_arrival_before_kickoff` h
(reason e.g. "Can't leave before Sat 9:00 AM and still arrive 3 h before kickoff"). Late hotel arrival is NOT infeasible
(A-09 flags it).

**Plan output:** `overnight` = strategy ≠ game_day; `nights` = overnight ? days between departure date and game date : 0
(min 1 when overnight); `trip_days` = calendar days from departure date to the return date inclusive (return is game day).

**En-route stop** (only if `route_stop_city` ≠ '' OR drive ≥ 150 min): at the drive midpoint. If a route stop city
exists and the stop starts 11:00–14:59 → 45-min **meal** "En-route lunch" (meal kind en_route_lunch, used by A-03); if 17:00–20:00
→ 45-min meal "Team dinner (en route)" (team_dinner). Otherwise a 20-min `stop` "Rest stop".

**Overnight items (day before):** depart (location "BGSU Football Complex, Bowling Green, OH"), stop/meal, arrive_hotel,
checkin (30 min), walkthrough at the stadium 60 min if check-in ends by 18:00, team dinner meal 60 min starting at the later of
18:30 or check-in end + 30 (skip if dinner already happened en route), meeting "Position meetings" 20:00–21:30 if it starts after
dinner ends, curfew 22:30 (or arrival + 60 min if later).

**Game day:** breakfast meal 08:30–09:15 only if kickoff ≥ 15:00. pregame_meal 45 min ending at kickoff −
`min_hours_meal_before_kickoff` h − 15 min. arrive_stadium = kickoff − 150 min. depart_hotel = arrive_stadium −
ceil5(miles_to_stadium / 25 mph × 60) − 10. kickoff item label "Kickoff vs <opponent>". depart_return = kickoff + 240 min
(label "Buses depart for home (boxed meal on bus)" + meal postgame_boxed). arrive_home = depart_return + drive_min + buffer.

**Same-day (`game_day`):** depart, optional stop/meal, arrive_stadium, kickoff, depart_return (+boxed meal), arrive_home.
