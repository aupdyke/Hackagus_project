# C-12 · Polish & accessibility pass (both roles)
**Track:** C · **Level:** EXT · **Estimate:** 60 min · **Branch:** `track-c`
**Depends on:** C-05 … C-10 (coordinate with B-16 for staff screens)

> Read `CLAUDE.md`. Usability is 10 pts and the demo runs on a projector, so prioritize big, clear and consistent.

## Steps
1. Athlete screens: consistent headers, spacing (`space` tokens), tap targets ≥ 48pt, loading/empty/error states everywhere.
2. Contrast: orange `#FE5000` on white fails WCAG AA for small text. Use brown/dark text for body copy and keep orange for
   large/bold text, buttons and accents. Check chips.
3. VoiceOver: `accessibilityLabel` / `accessibilityRole` on pressables, chips and countdown (`accessibilityLiveRegion` off for
   the ticking countdown); logical reading order on My Trip.
4. Dynamic Type: test with Larger Text; no clipped text in tab labels, cards or timeline.
5. Landing + app icon + splash consistent with BGSU colors (see C-02).
6. Shared kit (`components/ui.tsx`): only *add* exports; coordinate any change to existing ones with Track B.
7. Small delights if time allows: haptic on Send / Save (`expo-haptics` needs an install + rebuild, so skip unless rebuilding anyway).

## Files
- Track C files; additive changes to `components/ui.tsx`

- [ ] A person new to the app can find their bus, roommate and departure time in < 10 s.
