# B-09 · Step 4 Memo: live streaming on the phone
**Track:** B · **Level:** L2 · **Estimate:** 60 min · **Branch:** `track-b`
**Depends on:** B-05

> Read `CLAUDE.md`. The streamed trip memo is an Aivana streaming feature we demo live. Code computes the itinerary; the
> model writes prose from those facts only.

## Context
- Phase 0 already proved streaming: `app/dev/stream.tsx` uses `streamSse()` from `lib/sse.ts` (`fetch` from `expo/fetch`).
- URL: `streamUrl(API_URL, 'memoStream', { id })` (shared) with POST body `{ option_id?: string }` (defaults to the selected package).
- Events (`StreamEvent`): `{type:'delta', text}`, `{type:'done', finish_reason, unverified_sentences[]}`, `{type:'error', code, message}`.
- The finished memo is saved as `trip.memo = { markdown, generated_at, option_id, unverified_sentences }`.

## Steps
1. `MemoStep.tsx`: if `trip.memo` exists, show it with "Generated <time> for <option>" and a "Regenerate" button; else "Write memo".
2. While streaming: append deltas to state, auto-scroll, show a "Writing…" pulse, and a Stop button (`AbortController`).
3. `components/staff/MarkdownLite.tsx`: render `##`/`###` headings, `-` bullets, `**bold**`, paragraphs. No library.
4. On `done`: highlight sentences in `unverified_sentences` (amber background) + a note "⚠ Unverified — contains a figure not in
   our data". Invalidate `['trip', id]`.
5. On `error` (or a thrown error): `AiNotice(message)`, keep any partial text, offer Retry.
6. Under the memo: "Costs are estimates" caption.

## Files
- modify `components/staff/steps/MemoStep.tsx`; create `components/staff/MarkdownLite.tsx`

## Acceptance criteria
- [ ] Text visibly streams word by word on a real phone (not all at once).
- [ ] Stop works; leaving the screen aborts the stream.

## How to verify
`npm run dev:mock` → at Buffalo → select a package → Memo → Write memo → words appear progressively → done.
