# A-14 · Athlete trip assistant (multi-turn, structured, cited, never guesses)
**Track:** A · **Level:** EXT · **Estimate:** 60 min · **Branch:** `track-a`
**Depends on:** A-13 (athlete view). Can be built against `fixtures.FIXTURE_ATHLETE_VIEW` first.

> Read `CLAUDE.md`. Answers come only from a compact fact sheet of *this athlete's* trip. If a fact isn't there, the assistant
> says to ask a coach and sets `needs_staff: true`.

## Context
- Stub `buildFactSheet(view)` in `packages/shared/src/logic/athlete.ts` → `Fact[] = {id, text}`.
- Schema: `assistantSchema(factIds)` + `AiAssistantOut` (`ai/schemas.ts`):
  `{ answer (≤400 chars), cited_fact_ids: string[] enum of fact ids (≤5), needs_staff: boolean }`.
- Route stub: `assistant` in `apps/server/src/routes/athletes.ts`. Body `{ message, history[] }` (client keeps the history).
  Response `AssistantReply = { answer, cited_fact_ids, citations: Fact[], needs_staff, source: ai|fallback, fact_guard }`.
- Mock mode finds facts in the prompt with the regex `{"id":"…","text":"…"}`, so **send facts as a compact JSON array of
  `{id,text}`**.

## Steps
1. `buildFactSheet(view)`: one fact per itinerary item (`id` = `IT-n`, text `"<label> — <formatDayTime(start)> — <location>"`),
   `F-hotel` (name, address, phone), `F-bus` ("Your bus: Bus 2"), `F-room` ("Your room RM-04 with Jory Kettering"),
   one `F-meal-<ML-n>` per meal (kind, time, vendor), `F-packing` (list), `F-deadline` (roommate deadline if any),
   `F-opponent` (opponent, stadium, kickoff). Short texts only.
2. Route:
   - view = the current athlete view (reuse the A-13 helper). No published trip → `{ answer: "You don't have a published trip
     yet — please ask a coach.", needs_staff: true, source: 'fallback' }` with no AI call.
   - Rebuild the facts on **every** request. Trim history to the **last 6 turns**. messages = history + user message.
   - System (< 150 words): "You answer a student-athlete's questions about their own team trip using only FACTS (JSON list
     below). Cite fact ids you used. If the answer is not in FACTS, say they should ask a coach and set needs_staff true. Never
     guess times, places or names." + `FACTS_RULE` + `FACTS: <json>`.
   - `chat(messages, { schema: assistantSchema(ids), zod: AiAssistantOut, feature:'assistant', max_tokens: 300, temperature: 0 })`.
   - Verify: drop cited ids not in the facts (record an issue). Run `factGuard(answer, allowed-from-facts)` (times/dates/ids in
     the facts). If it fails, or there are no citations while `needs_staff` is false → answer =
     "I couldn't verify that from your trip info — please ask a coach.", `needs_staff: true`, `fact_guard.replaced: true`.
   - `citations` = the resolved Fact objects (the app renders them as tappable chips).
   - `AiError` → deterministic fallback: keyword → fact (leave/depart → the depart item, roommate/room → F-room, bus → F-bus,
     hotel → F-hotel, dinner/lunch/breakfast/eat → the next meal), else "AI is unavailable — check My Trip or ask a coach."
     `source: 'fallback'`.
3. Tests: fact ids are unique and include F-room; route (mock) "Who's my roommate?" cites F-room; "What's the WiFi password?"
   → needs_staff true; an athlete cannot query another athlete's id (403 from selfOnly).
