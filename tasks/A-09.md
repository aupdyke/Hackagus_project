# A-09 · Risk flags
**Track:** A · **Level:** L3 · **Estimate:** 60 min · **Branch:** `track-a`
**Depends on:** A-02, A-03

> Read `CLAUDE.md`. Risk flags are generated by **code**, in plain language, and shown on each package card.

## Context
Stub `computeRiskFlags(pkg, { game, hotel, settings, request, seasonShare? })` in `packages/shared/src/logic/risk.ts`.
`buildPackages` (A-03) already calls it inside a try/catch. The server passes `seasonShare = budget ÷ away games`
(`features/planner.ts`). `RiskFlag = { code, severity: info|warning|critical, message, option_id, related_item_id }`.

| code | severity | rule |
|---|---|---|
| late_hotel_arrival | warning | arrive_hotel start clock > `settings.latest_hotel_arrival` (or next day) |
| arrival_close_to_kickoff | critical | arrival at destination < `min_hours_arrival_before_kickoff` h before kickoff |
| meal_close_to_kickoff | warning | a meal (not postgame_boxed) ends < `min_hours_meal_before_kickoff` h before kickoff (also warn if within +30 min of the limit) |
| bus_near_capacity | info | travelers > 95% of buses × seats_per_bus |
| insufficient_rooms | critical | rooms_total > hotel.rooms_available |
| meal_over_allowance | warning | one flag per package listing the meals with price > allowance |
| dietary_gap | warning | per meal with gaps; message includes the number of travelers affected |
| over_season_share | warning | total > seasonShare |
| infeasible_departure | critical | `pkg.feasible === false` (message = infeasible_reason) |
| over_cap | warning | lodging→hotel, meals→meals, bus→bus+equipment, total→total exceeds `request.caps` |

Messages use code-formatted values (`formatClock`, `formatUSD`), e.g. "Arrives at hotel 11:40 PM — after the 11:00 PM latest
arrival setting." and "Lodging $10,825 is over the $9,000 cap."
