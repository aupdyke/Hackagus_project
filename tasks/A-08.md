# A-08 · Memo facts + fact-guard flagging for the streamed memo
**Track:** A · **Level:** L2 · **Estimate:** 45 min · **Branch:** `track-a`
**Depends on:** A-03, A-04

> Read `CLAUDE.md`. Streaming already works end to end (Phase 0): `POST /trips/:id/memo/stream` relays SSE events
> `{type:'delta'|'done'|'error'}`. This task makes the facts proper and flags unverified sentences.

## Context
- `apps/server/src/features/memo.ts`: uses `memoFacts` from shared if implemented, otherwise `basicFacts`. After the stream it
  runs `factGuard(text, allowed).bad_sentences` and sends `done { unverified_sentences }`, then saves `trip.memo`.
- Stub: `memoFacts(game, req, pkg)` in `packages/shared/src/logic/facts.ts` → `{ facts, allowed }`.
- `MEMO_SYSTEM` prompt is in memo.ts (keep < 150 words).

## Steps
1. Implement `memoFacts`: facts = `{ opponent, city, stadium, kickoff (formatDayTime), option_id, label, hotel: pkg.hotel_name,
   travelers, buses, rooms, nights, estimated_total (number), itinerary:[{id, time: formatDayTime(start), what: label, where}],
   meals:[{time, vendor, headcount}], risks:[message] }`. Keep it compact (no roster).
   allowed = `factsFromPackages([pkg])` plus game date/kickoff and every itinerary time.
2. In memo.ts remove the `basicFacts` fallback (keep the code path simple) and tell the model the memo must label any total as an
   estimate.
3. The `done` event already carries `unverified_sentences`. Make sure the saved `trip.memo.unverified_sentences` matches.
4. Tests: `memoFacts.allowed.times` includes every itinerary start time; `factGuard` flags a sentence containing "3:15 AM" when
   that time isn't in the facts; a streamed memo in mock mode completes with `done`.
