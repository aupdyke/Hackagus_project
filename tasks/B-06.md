# B-06 · AI recommendation badge + tradeoffs (with fallbacks)
**Track:** B · **Level:** L1 · **Estimate:** 45 min · **Branch:** `track-b`
**Depends on:** B-05

> Read `CLAUDE.md`. Aivana recommends one package by ID and explains the tradeoffs. Show costs from package data only.

## Context
- `api.recommend({ params: { id } })` → `Recommendation = { recommended_option_id, ranking[], tradeoffs[{option_id, pros[], cons[]}],
  explanation, source: 'ai'|'template', fact_guard: { passed, replaced, issues[] }, created_at }`. Also stored on
  `trip.recommendation` (cleared by the server when the request changes).
- Server fallbacks: AI down → `source: 'template'` (a code recommendation); the fact guard replaced unverifiable prose →
  `fact_guard.replaced: true`.

## Steps
1. In `PackagesStep.tsx` above the cards: a "Get AI recommendation" button (or "Refresh") → `useRecommend`.
2. `components/staff/RecommendationPanel.tsx`:
   - "AI pick" orange badge on the recommended card (pass `recommendedId` into `PackageCard`), plus a ranking line
     ("1. PKG-G10-B · 2. PKG-G10-A · 3. PKG-G10-C" shown as labels).
   - Explanation text. Tradeoffs: per option, pros (✓) and cons (✗).
   - `source === 'template'` → chip "Code recommendation (AI unavailable)". `fact_guard.replaced` → chip "AI text replaced —
     unverifiable figure" (tap to show the issues).
   - "Select recommended" shortcut button.
3. Error → `AiNotice(errorMessage(e))`; the packages stay fully usable.

## Files
- create `components/staff/RecommendationPanel.tsx`; modify `PackagesStep.tsx`, `PackageCard.tsx` (badge prop)
