## Algorithm (spec §2)
Player room size k = `settings.player_room_occupancy`. Only traveling players count. Ignore requested ids that aren't traveling.
1. **Mutual** requests first: for pairs that requested each other, put both in a new room. If k > 2, add mutual partners of
   occupants while there is space.
2. **One-way**: for each still-unassigned requester (by id), join the first requested player's room if it has space; else if
   that player is unassigned, create a room with both.
3. **Rest**: sort by (position_group, class_year, travel_priority). Fill partially filled rooms first, then new rooms.
- `requests_total` = number of (requester, requested) pairs among travelers; `requests_honored` = pairs sharing a room.
- Coaches: rooms of `coach_room_occupancy` (by id); support: `support_room_occupancy`; then `driverRooms` driver rooms.
- Room ids are sequential RM-01… in the order players, coaches, support, drivers.
- `validateRooming(rooming, travelerIds, settings)`: every traveler appears exactly once, no unknown ids (except `DRIVER-n`),
  occupancy ≤ limit per kind, players only in player rooms. Returns error strings.
- `assignBuses(players, staff, buses, seats)`: head coach (first coach) on bus 1, coaches alternate; offense groups
  (QB RB WR TE OL) fill from bus 1, defense (DL LB DB) from the last bus, ST anywhere; support staff fill the remaining seats.
  Never exceed seats. Deterministic.

## Server steps
1. `generateRooming`: requires `request` and a selected package (409 otherwise). Travelers = `selectTravelingPlayers` /
   `selectTravelingStaff`. `driverRooms = pkg.counts.rooms_drivers`. Save rooming, traveling ids and buses
   (`assignBuses(..., pkg.counts.buses, pkg.counts.seats_per_bus)`).
2. `updateRooming`: `validateRooming` → 400 with the error list in `details`; recompute `requests_honored`; set `edited: true`.
3. In `routes/trips.ts` `submitRequest` (Track A file): set `roommate_deadline_local` =
   (departure date of package A, or game date − 1) − `roommate_request_deadline_days_before` days, at `23:59`, if empty.
