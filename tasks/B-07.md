# B-07 · Settings screen (every setting editable) + reset demo data
**Track:** B · **Level:** L1 · **Estimate:** 60 min · **Branch:** `track-b`
**Depends on:** B-01

> Read `CLAUDE.md`. Hackathon rule: **seats per bus, room occupancy and meal allowance are editable settings.** Show
> "costs are estimates" on this screen.

## Context
- `api.getSettings()` / `api.putSettings({ body: Settings })`. Saving recomputes every open trip server-side.
- `Settings` (domain.ts): seats_per_bus_override (int ≥ 1 | null = use the bus company), player_room_occupancy (1–4),
  coach_room_occupancy, support_room_occupancy, meal_allowance_per_meal, avg_bus_mph (20–80), departure_buffer_min,
  min_hours_arrival_before_kickoff, min_hours_meal_before_kickoff, latest_hotel_arrival ('HH:MM'), contingency_pct (0–50),
  season_travel_budget, default_bus_company_id ('BUS-1'|'BUS-2'|'BUS-3'), roommate_request_deadline_days_before, packing_list[].
- `ESTIMATE_NOTE` from shared. `api.resetDemo()` re-seeds the DB.

## Steps
1. Replace `app/(staff)/settings.tsx` with grouped sections: **Buses** (override toggle "Use bus company default" + seats input,
   default company picker), **Rooms** (three occupancy steppers), **Meals** (allowance $), **Timing** (mph, buffer, min hours ×2,
   latest hotel arrival), **Budget** (contingency %, season budget $), **Athletes** (roommate deadline days, packing list editor:
   add / remove / edit rows).
2. Local form state, validation with the shared `Settings` Zod schema (`Settings.safeParse`), inline errors, and a sticky Save bar
   that appears when there are changes → `useSaveSettings` → toast/banner "Saved — all open trips recomputed."
3. Show `AiNotice(ESTIMATE_NOTE)` at the top.
4. "Reset demo data" (ghost, bottom) → confirm `Alert` → `useResetDemo` → invalidate everything.

## Files
- modify `app/(staff)/settings.tsx`; create `components/staff/settings/*` as needed

## Acceptance criteria
- [ ] Changing seats per bus (e.g. 50) or occupancy (e.g. 3) changes package costs after save.
- [ ] Invalid values can't be saved.

## How to verify
`npm run dev:mock` → Settings → player room occupancy 3 → Save → Trips → at Buffalo → Packages → rooms / hotel cost changed.
