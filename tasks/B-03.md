# B-03 · Step 1 Request: form mode
**Track:** B · **Level:** L1 · **Estimate:** 75 min · **Branch:** `track-b`
**Depends on:** B-02

> Read `CLAUDE.md`. The core planner must work with AI fully down, so the form path never touches AI.

## Context
- `TripRequest` (domain.ts): `{ game_id, players 1–150, coaches 0–40, support_staff 0–60, departure_constraint:{kind:
  none|not_before|not_after, datetime_local:'' | 'YYYY-MM-DDTHH:MM', raw_text}, include_equipment_truck, caps:{lodging,meals,bus,total
  (number|null)}, excluded_hotel_ids:[], preference:'none'|…, notes }`.
- Submit: `api.submitRequest({ params: { gameId: game.game_id }, body })` → `TripDetail` (status becomes draft, packages computed).
  Server 400s carry readable messages (e.g. "Departure constraint needs a day and time").
- Shared helpers: `resolveDay(gameDate, 'day_before'|'game_day'|'two_days_before'|'fri'…)`, `combine(date, 'HH:MM')`,
  `formatDayTime`, `isValidClock`.
- Defaults when `trip.request` is null: 70 players, 12 coaches, 12 support, truck on, no constraint.

## Steps
1. `components/staff/RequestForm.tsx` (reusable; B-04 uses it for review): props `{ game, initial: Partial<draft>, missing?:
   string[], onSubmit(req), submitting }`.
   - Number steppers (− / + and direct input) for players / coaches / support, with bounds.
   - Departure constraint: segmented None / Not before / Not after. When not None: day chips (2 days before / Day before /
     Game day) and a time field (HH:MM with ±15 min buttons). Show the resolved value ("Not before Fri Nov 27, 2:00 PM").
   - Equipment truck switch; notes field.
   - Highlight fields listed in `missing` with an orange border and "Please fill in".
   - Client validation mirrors the server bounds; show server errors inline too.
2. `RequestStep.tsx`: mode toggle **Form | Free text** (free text arrives in B-04; render a placeholder for now). Form mode →
   `RequestForm` → `useSubmitRequest` → on success `goTo('packages')`.
3. Keep `caps`, `excluded_hotel_ids` and `preference` from the existing request if present (the what-if may have set them);
   default null / [] / 'none'.
