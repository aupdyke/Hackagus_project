## Context
The cost engine is the heart of Level 1 (30 pts "core functionality"). Every number staff see comes from these
pure functions in `packages/shared`. The stubs already exist with typed signatures and throw `NotImplementedError('A-01')`.

Formulas (spec §6):
```
travelers = players + coaches + support            (drivers counted separately, lodging only)
seats     = settings.seats_per_bus_override ?? bus.seats_per_bus
buses     = max(1, ceil(travelers / seats))
drivers   = buses + (include_equipment_truck ? 1 : 0)
rooms_drivers = overnight && bus.driver_room_required_overnight ? drivers : 0
rooms_players = ceil(players / settings.player_room_occupancy)
rooms_coaches = ceil(coaches / settings.coach_room_occupancy)
rooms_support = ceil(support / settings.support_room_occupancy)
rooms_total   = rooms_players + rooms_coaches + rooms_support + rooms_drivers
bus_cost  = buses × (daily_rate × trip_days + per_mile_rate × round_trip_miles)
            + rooms_drivers × hotel.nightly_rate × nights × (1 + hotel.tax_rate)     (0 if hotel null)
equipment = truck ? equipment_truck_daily_rate × trip_days + equipment_truck_per_mile_rate × round_trip_miles : 0
hotel     = (rooms_total − rooms_drivers) × nightly_rate × nights × (1 + tax_rate)   (driver rooms billed in bus_cost)
subtotal  = bus + equipment + hotel + meals
contingency = subtotal × contingency_pct / 100 ;  total = subtotal + contingency
```
Round every output to cents with `round2` (`packages/shared/src/logic/money.ts`).

Who travels: players are the **eligible** players (`travel_eligible`) sorted by `travel_priority` ascending, take the
first N (fewer if not enough eligible). Staff: per category (`coach` / `support`), sort by `travels_by_default` desc then `id`
asc, take N.

Types: `TravelCounts`, `CostBreakdown`, `Settings`, `BusCompany`, `Hotel`, `TripRequest`, `Player`, `StaffMember` in
`packages/shared/src/domain.ts`. Test data loader: `loadDataPack()` / `planningData()` from `packages/shared/src/testing/loadData.ts`.
