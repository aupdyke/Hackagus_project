# A-16 · "Get back under budget": AI selects candidates, code verifies + applies
**Track:** A · **Level:** EXT · **Estimate:** 60 min · **Branch:** `track-a`
**Depends on:** A-15, A-04

> Read `CLAUDE.md`. Aivana picks a set of candidate **IDs** and explains why. Code checks every ID exists and recomputes the
> total. The model never states a dollar figure.

## Context
- Routes (fixtures today): `seasonSavings` (`POST /season/savings`) and `applySavings` (`POST /season/savings/apply`,
  body `{candidate_ids}`, returns `SeasonRollup`) in `apps/server/src/routes/season.ts`.
- Schema: `savingsSchema(candidateIds)` + `AiSavingsOut` (`ai/schemas.ts`): `{ selected_candidate_ids: enum[], explanation ≤600 }`.
- Stub `savingsFacts(candidates, overBy)` in `logic/facts.ts`.
- `SavingsResult = { candidates, selected_candidate_ids, explanation, projected_before, projected_after, total_savings,
  back_under_budget, source: ai|template, fact_guard }`.

## Steps
1. `savingsFacts`: facts `{ budget, projected, over_by, candidates:[{id, trip (opponent), kind, description, savings}] }`.
   allowed = all those money values + ids.
2. `seasonSavings`:
   - rollup + candidates (A-15). Not over budget or no candidates → template result, explanation "Season is within budget — no
     changes needed." (no AI call).
   - System (< 150 words): pick the smallest set of candidates that brings projected under budget, prefer changes to trips
     further in the future and fewer roster cuts, at most one package switch per trip, explain in ≤ 3 sentences referring to
     candidate IDs, **no dollar amounts**; `FACTS_RULE`.
   - Verify: ids exist, dedupe, enforce one switch per trip → `applySavings` → projected_after, back_under_budget.
   - Fact guard on the explanation (retry once with a correction note, then a template explanation + replaced flag).
   - `AiError` → template greedy selection (sort by savings, skip conflicts, stop once under budget), `source: 'template'`.
3. `applySavings` route: recompute the candidates **now**; unknown id → 400. Apply per kind: switch_package → set
   `selected_option_id`; reduce_travelers → `request.players -= 5` then `computeTripPackages` (keep the same tier selected);
   cheaper_hotel → add the hotel to `excluded_hotel_ids` then recompute (same tier). Save trips and return the new `rollupSeason`.
4. Tests: greedy template stops when under budget; an invented `$` in the explanation gets replaced; apply changes G12's
   selection and lowers the projected total; an unknown id → 400.
