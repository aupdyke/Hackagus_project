## Context
- `api.getRooming({params:{id}})` → `Rooming | null`; `api.generateRooming({params:{id}})` → `Rooming`;
  `api.updateRooming({params:{id}, body:{rooms}})` → `Rooming` (400 with a readable message + `details` listing errors if invalid).
- `Rooming = { rooms: [{room_id, kind: player|coach|support|driver, occupant_ids}], requests_honored, requests_total, edited, generated_at }`.
- Names: `api.listAthletes()` gives players (id → "First Last", #jersey, position). Staff ids (S-xxx) → show "Staff S-013";
  drivers → "Bus driver".

## Steps
1. `RoomingStep.tsx`: no rooming → "Generate rooming list" button. Otherwise:
   - Summary card: "Roommate requests honored 9 / 12", rooms count by kind, "Edited by staff" chip if `edited`.
   - Sections: Player rooms, Coach rooms, Support rooms, Driver rooms, each room a row: RM-04 · names.
   - **Swap mode**: tap person A (highlight) then person B in another room → swap locally; "Save changes" / "Discard" bar.
   - Save → `useUpdateRooming`; show server validation errors in a list.
   - "Regenerate" (confirm: discards manual swaps).
2. Search box to find a player's room quickly.
3. Note: after publish, saving shows "Re-publish to notify athletes".
