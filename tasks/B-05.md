# B-05 · Step 2 Packages: side-by-side cards with code-computed costs
**Track:** B · **Level:** L1 · **Estimate:** 75 min · **Branch:** `track-b`
**Depends on:** B-02 (B-01 components)

> Read `CLAUDE.md`. Costs shown here come from the package data only (code), always labeled Estimate.

## Context
`TravelPackage` (domain.ts): option_id, tier A/B/C, label Economy/Balanced/Game-Ready, feasible, infeasible_reason, hotel_name,
departure_local, return_local, nights, trip_days, round_trip_miles, counts{players,coaches,support,travelers,drivers,buses,
seats_per_bus,rooms_*}, meals[MealLine{kind,vendor_name,time_local,headcount,price_per_person,cost,over_allowance,dietary_gaps}],
costs{bus,equipment,hotel,meals,subtotal,contingency,total}, itinerary[], risk_flags[]. `trip.selected_option_id`.
Mutations: `useSelectPackage(id)` (`api.selectPackage({params:{id}, body:{option_id}})`), `useComputePackages(id)`.

## Steps
1. `components/staff/PackageCard.tsx`: label + option id, hotel, "Departs Fri Nov 27, 12:00 PM · back Sat 7:45 PM" (`formatDayTime`),
   nights, travelers / buses / rooms, `CostTable`, `RiskFlagList`, an expandable meals list (vendor, time, $/person, "over allowance"
   and dietary-gap chips), an infeasible banner with the reason, and a Select button (disabled if infeasible; shows "Selected").
2. `PackagesStep.tsx`: a horizontal paged `ScrollView` / `FlatList` (snap, ~85% width cards so the next one peeks), page
   dots, a "Recompute" ghost button, and "Next: What-if" / "Skip to Publish" actions. Selected card has an orange border.
   No packages → Empty with "Submit a request first" + goTo('request').
3. Leave a slot above the cards for the AI recommendation (B-06).
4. Accessibility: card label "Economy option, total estimate $26,350, 1 warning".
