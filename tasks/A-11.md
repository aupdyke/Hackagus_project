# A-11 · Travel packet HTML (staff / athlete / public share page)
**Track:** A · **Level:** L3 + EXT · **Estimate:** 75 min · **Branch:** `track-a`
**Depends on:** A-10 (rooming + buses). Works with whatever trip data exists.

> Read `CLAUDE.md`. The app prints the HTML to PDF (`expo-print`) and shares it. The same renderer powers
> `/share/:tripId/:token`.

## Context
- Route stubs: `getPacket` in `apps/server/src/routes/tripsPublish.ts` (`GET /trips/:id/packet?audience=staff|athlete&athleteId=`)
  and the share page in `apps/server/src/routes/share.ts` (already checks a random token in constant time and requires status
  `published`).
- `Packet = { trip_id, audience, title, html, share_url }`. `shareUrl()` helper exists in tripsPublish.ts.
- Data helpers: `apps/server/src/data.ts` (`pack`, `playerName`, `staffById`, `hotelById`), settings via `repo.settings.get()`.

## Content (spec §2 "Travel-day outputs")
- **Staff packet**: header (BGSU Falcons at Opponent, date, kickoff, stadium), itinerary table (time, item, location), bus
  manifest (bus → names), rooming list (room → names), meal schedule with headcounts and dietary notes, key contacts
  (`key_contact` staff, plus the hotel and bus company phones, all synthetic), cost summary (bus, equipment, hotel, meals,
  contingency, total), every amount labeled **Estimate**.
- **Athlete packet** (`athleteId` required and must be on the traveling roster): itinerary, *their* bus number, *their* room +
  roommate names only, meal times and vendors, hotel name/address/phone, key contacts, packing list. **No costs, no other
  athletes' names** (except roommates).
- **Public share page** (`audience: 'public'`, internal): itinerary, hotel, meals, contacts, packing list. No names, no costs.
- Footer on all: "Synthetic data — 2026 BGSU Hackathon. Costs are estimates." BGSU colors (#FE5000 / #4F2C1D), print CSS
  (`@page { margin: 14mm }`, `page-break-inside: avoid` on tables), system fonts, mobile viewport.
- **Escape every string** (names come from data; never trust input).

## Steps
1. `apps/server/src/features/packet.ts`: `renderPacketHtml({ trip, game, pkg, audience, athleteId? })` → `{ title, html }`.
2. Wire `getPacket`. Allow athletes too: athlete role may call it only with `audience=athlete` and `athleteId` equal to its
   `X-Athlete-Id`. Replace the router-level `staffOnly` for this one route with a custom check, and note that in the commit.
3. Share page → render the public variant.
4. Tests: staff html contains "Estimate" and the total; athlete html has no "$" and contains the roommate name but not another
   random traveler's name; a `<script>` in a name is escaped; bad token → 404; unpublished trip → 404.
