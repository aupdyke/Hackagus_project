# A-04 · Fact guard
**Track:** A · **Level:** L1 · **Estimate:** 75 min · **Branch:** `track-a`
**Depends on:** none

> Read `CLAUDE.md`. This is a reliability feature we show in the demo. All model prose passes through it.

## Context
Stub `factGuard(text, allowed)` in `packages/shared/src/logic/factGuard.ts` returns
`FactGuardResult & { bad_sentences }` where `FactGuardResult = { passed, replaced, issues[] }`. `AllowedFacts` is
`{ money: number[], quantities: Record<unit, number[]>, times: 'HH:MM'[], dates: 'YYYY-MM-DD'[], ids: string[] }`.

Spec §4: any dollar amount, number with units (miles, hours, rooms, buses…), clock time or date in the text must match a value
our code supplied for that call. Every option/candidate/fact ID mentioned must exist. On failure, callers (A-05, A-07,
A-08, A-14, A-16) retry once with a correction note, then replace the prose with a code template and show a badge.

## Rules
- **Money**: `$1,234`, `$1,234.56`, `$9.8k`, `$12K` → number. A match is within ±$1 of an allowed value (±1% for `k` forms).
- **Quantities**: `<number> <unit>`. Normalize the units: mile(s)/mi → mile; hour(s)/hr(s)/h → hour; minute(s)/min(s) → minute;
  room(s); bus/buses → bus; player(s); coach(es); staff; traveler(s); night(s); meal(s); `%` → percent. Word numbers
  one–twenty count too ("three players"). Exact match after normalization (hours ±0.05).
- **Times**: `2 PM`, `2:30 p.m.`, `14:30`, `noon` (12:00), `midnight` (00:00) → HH:MM, must be in `allowed.times`.
- **Dates**: `Nov 28`, `November 28`, `11/28`, `2026-11-28` → must be in `allowed.dates` (year optional). Weekday names
  (Friday, Sat…) must equal the weekday of some allowed date (`dayOfWeek` in time.ts).
- **IDs**: `PKG-…-[ABC]`, `SAV-n`, `IT-n`, `F-…`, `H-XXX-n`, `R-XXX-n`, `ML-n` → must be in `allowed.ids`.
- Bare numbers without units are ignored, except years (2026 is fine).
- `issues`: one human-readable string per violation, e.g. `"$9,999 is not in the facts"`.
  `bad_sentences`: the sentences (split on `.!?` or newline) that contain a violation. `passed = issues.length === 0`. `replaced` is always false here (callers set it).
- Export helpers: `emptyFacts()` (exists), `mergeFacts(...facts)`, and `factsFromPackages(pkgs)`. The last one collects
  each package's totals and components, pairwise **differences between totals** (the model may say "saves $4,412"), counts
  (travelers, buses, rooms, nights, players…), departure/return and itinerary times, dates, option IDs, hotel IDs and restaurant IDs.
