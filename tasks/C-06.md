# C-06 · Trip assistant chat (citation chips, needs-staff state)
**Track:** C · **Level:** EXT · **Estimate:** 75 min · **Branch:** `track-c`
**Depends on:** C-05 (A-14 for real answers; the server returns a fixture reply until then)

> Read `CLAUDE.md`. Answers come only from the athlete's own trip facts. Each citation is a tappable chip linking to the
> itinerary item. If the answer isn't known, the assistant says to ask a coach. Demo step 6: "Who's my roommate?".

## Context
- `api.assistant({ params:{ id: athleteId }, body:{ message, history } })` → `AssistantReply = { answer, cited_fact_ids[],
  citations:[{id, text}], needs_staff, source: 'ai'|'fallback', fact_guard:{passed, replaced, issues} }`.
- The client keeps `history: [{role:'user'|'assistant', content}]`; send at most the last 6 turns (the server trims too).
- Fact ids: `IT-n` = itinerary items (link to My Trip `?focus=IT-n`), `F-room`, `F-bus`, `F-hotel`, `F-meal-ML-n`, `F-packing`, …
- A generic `ChatBubble` may exist from Track B (`components/staff/ChatBubble.tsx`). Reuse it if it's there, otherwise create
  `components/athlete/Bubble.tsx`.

## Steps
1. Replace `app/(athlete)/assistant.tsx`: message list, an input with Send (disabled while pending), typing indicator,
   `KeyboardAvoidingView`.
2. Suggested question chips on an empty chat: "When do we leave?", "Who's my roommate?", "What's for dinner Friday?",
   "What bus am I on?", "What should I pack?".
3. Assistant bubble: answer text + citation chips (short label from `citations[].text`). Tap an `IT-*` chip →
   `router.push({ pathname: '/(athlete)/my-trip', params: { focus: id } })`. Tap an `F-*` chip → show the fact text in a small sheet.
4. `needs_staff` → amber "Ask a coach" pill under the bubble. `fact_guard.replaced` → small "Answer limited to verified trip info"
   caption. `source: 'fallback'` → `AiNotice` "AI is unavailable — showing what we can find".
5. Keep the conversation in component state (per athlete); a "New chat" button clears it.
