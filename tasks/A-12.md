## Steps
1. `budgetVsActual`: planned from the selected package's `costs` (other = 0, contingency = costs.contingency, actual null for
   contingency). variance = actual − planned (round2). `planned_total = costs.total`; `actual_total = bus+equipment+hotel+meals+other`;
   `variance_total = actual_total − planned_total`. No actual → actual/variance null. Throw a clear Error if there is no selected package.
2. Routes: no selected package → 409. `postActuals` rejects negative numbers (400) and only accepts trips with status
   `published` or `completed`. On success, set status `completed` (published → completed) and save.
3. Remove the `orFixture` usage in these two routes.
4. Tests for the pure function plus a route test with the seeded G02 actuals.
