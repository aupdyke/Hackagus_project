## Context
- `api.aiUsage()` → `AiUsageSummary = { totals:{calls, errors, input_tokens, output_tokens, credits, avg_latency_ms},
  by_feature:[{feature, calls, input_tokens, output_tokens, credits, avg_input_tokens}], recent: AiCallLog[] (feature, endpoint, ok,
  error_code, input/output tokens, credits, latency_ms, request_id, attempts, mock, created_at), mock_mode }`.
- `api.aiAccuracy()` → `AccuracyReport | null = { run_at, mock, cases_run, per_field:[{field, correct, total, accuracy}],
  overall_accuracy, exact_match_rate, recommendation_valid_id_rate, fact_guard_pass_rate, failures[] }`.

## Steps
1. Replace `app/(staff)/ai.tsx` with two segments, **Accuracy** | **Usage**.
2. Accuracy: big overall % tile, exact-match %, recommendation-valid-ID %, fact-guard pass %; per-field horizontal bars (field name,
   bar, "22/24"); "Run at … · 24 cases · live / mock" caption; a collapsible failures list. Null → Empty "No accuracy run yet — run
   `npm run accuracy`".
3. Usage: totals tiles (calls, errors, tokens in/out, credits, avg latency), per-feature table (avg input tokens highlights how small
   our prompts are), recent calls list (feature · ok/error code · tokens · ms · request id, mock chip). "Mock mode" banner if
   `mock_mode`.
4. Pull-to-refresh on both.
