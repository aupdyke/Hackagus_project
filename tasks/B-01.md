# B-01 · Staff data hooks + money / cost / risk components
**Track:** B (Staff app) · **Level:** L1 · **Estimate:** 45 min · **Branch:** `track-b`
**Depends on:** none (Phase 0)

> Read `CLAUDE.md`. Build every staff screen in mock mode (`npm run dev:mock`). Every total shows an "Estimate" label.
> The app displays costs from our data, never from model text.

## Context
- Typed client: `api` from `apps/mobile/lib/api.ts` (generated from `packages/shared/src/api.ts`). Example:
  `api.getTrip({ params: { id } })`, `api.submitRequest({ params: { gameId }, body })`, `api.getPacket({ params:{id}, query:{audience:'staff'} })`.
  Errors are `ApiClientError` with `.code`; `errorMessage(e)` gives friendly text; `isAiError(e)`.
- React Query is set up in `app/_layout.tsx`. UI kit: `components/ui.tsx`. Theme: `lib/theme.ts`.
- Types: import from `@falcon/shared` (`Trip`, `TravelPackage`, `CostBreakdown`, `RiskFlag`, `TripStatus`, …).

## Steps
1. `apps/mobile/lib/staff/queries.ts`:
   - queries: `useTrips()`, `useTrip(id)`, `useSettings()`, `useSeason()`, `useRooming(id)`, `useBudgetVsActual(id)`,
     `useAiUsage()`, `useAiAccuracy()`, `useAthletes()`.
   - mutations (each invalidates the right keys and writes `['trip', id]` from TripDetail responses): `useSubmitRequest(gameId)`,
     `useParseRequest()`, `useComputePackages(id)`, `useRecommend(id)`, `useWhatIf(id)`, `useSelectPackage(id)`, `useApprove(id)`,
     `usePublish(id)`, `useGenerateRooming(id)`, `useUpdateRooming(id)`, `usePostActuals(id)`, `useSaveSettings()`
     (invalidates trips, season, every trip), `useSavings()`, `useApplySavings()`, `useResetDemo()` (invalidates everything).
   - Query keys exactly as in CLAUDE.md.
2. `apps/mobile/components/staff/`:
   - `Money.tsx`: `<Money value={n} size="lg|md" />` → `formatUSD` + a small "Estimate" caption. `<MoneyDelta value>` (green when
     negative or saving, red when positive).
   - `CostTable.tsx`: rows bus / equipment / hotel / meals / contingency / **total** with `EstimateBadge`.
   - `RiskFlagList.tsx`: severity icon and color (critical red, warning amber, info blue) + message; empty → "No risk flags".
   - `StatusChip.tsx`: not_started (neutral), draft (brand), approved (info), published (ok), completed (neutral).
   - `Section.tsx`: titled section with an optional right-side action.
3. Add any small generic primitive you need to `components/ui.tsx` (Track B owns it). Don't change existing signatures.
