# C-05 · My Trip screen (countdown, timeline, bus/room, packing list)
**Track:** C · **Level:** EXT · **Estimate:** 90 min · **Branch:** `track-c`
**Depends on:** C-01 (A-13 for real data; the server returns a fixture view until then)

> Read `CLAUDE.md`. The athlete sees their next published trip: countdown to departure, personal itinerary, bus number, hotel and
> roommate, meal times, packing list, and an itinerary share button (C-10).

## Context
- `api.myTrip({ params: { id: athleteId } })` → `MyTripResponse = { athlete:{id,name,jersey,position}, trip: AthleteTripView | null,
  open_roommate_requests:[{trip_id, opponent, deadline_local}] }`.
- `AthleteTripView`: game{opponent, city, state, stadium_name, date, kickoff_local}, hotel{name, address, phone}, bus_number,
  room_id, roommates[{id,name}], itinerary[ItineraryItem{id, kind, label, start_local, end_local, location}], meals[{meal_id, kind,
  time_local, vendor_name, itinerary_item_id}], packing_list[], departure_local, roommate_deadline_local, published_at, share_url, version.
- Time helpers: `formatDayTime`, `formatDate`, `formatClock`, `hoursBetween` (shared). Local datetimes have no time zone; treat them
  as device local time for the countdown (`new Date(y, m-1, d, hh, mm)`).

## Steps
1. Replace `app/(athlete)/my-trip.tsx`:
   - Hero: "BGSU at <Opponent>", date · kickoff · stadium; **countdown** to `departure_local` ("Departs in 2d 14h 05m", ticking every
     minute; past → "On the road" / "Trip complete").
   - Quick cards row: **Bus** (big number), **Room** (room id + roommate names), **Hotel** (name, address; tap → phone call via
     `Linking.openURL('tel:')`).
   - **Timeline**: vertical list of itinerary items grouped by day (Fri / Sat), time on the left, label + location; meals get a fork
     icon; the next upcoming item is highlighted. Each item has `nativeID`/ref so the Assistant's citation chips (C-06) can scroll here
     (accept a route param `focus=IT-5` and scroll/highlight it).
   - **Packing list** with local-only checkboxes.
   - Banner if `open_roommate_requests` is non-empty: "Pick your roommates by <deadline>" → Roommates tab.
   - "Version 2 · updated <time>" caption.
2. Empty state (`trip: null`): friendly "No published trip yet" + a roommate banner if open.
3. Refetch on focus and every 60 s.
