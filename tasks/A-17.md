# A-17 · AI accuracy harness (+ results for the "AI Accuracy" screen)
**Track:** A · **Level:** EXT · **Estimate:** 75 min · **Branch:** `track-a`
**Depends on:** A-06 (parse is solid). Recommendation checks need A-05.

> Read `CLAUDE.md`. 20+ free-text trip requests with known correct parses. The script calls the real parse endpoint,
> compares field by field and writes `tests/accuracy/results/latest.json`, which `GET /ai/accuracy` serves to the app.

## Context
- `npm run accuracy` → `tsx tests/accuracy/run.ts` (root package.json script already exists).
- Report shape: `AccuracyReport` in `domain.ts`: `{ run_at, mock, cases_run, per_field:[{field,correct,total,accuracy}],
  overall_accuracy, exact_match_rate, recommendation_valid_id_rate, fact_guard_pass_rate, failures:[{case_id,field,expected,got}] }`.
- Endpoints: `POST /trips/parse {text}` → `ParseResult.draft`; `POST /trips/:id/recommend` → `Recommendation`;
  `GET /trips/:id` → packages. Server must run separately (`npm run dev:server`, with `AIVANA_MOCK=0` for real numbers).
- Schedule: away games G02 Kent State (Oct 3), G04 Western Michigan (Oct 17), G06 Ball State (Oct 31), G08 Miami (OH)
  (Nov 14), G10 Ohio (Sat Nov 28), G12 Buffalo (Sat Dec 12). Home: Robert Morris, Akron, Toledo, Central Michigan,
  Eastern Michigan, Massachusetts.

## Steps
1. `tests/accuracy/cases.json`: ≥ 24 cases `{ id, text, expected: { game_id|null, players|null, coaches|null,
   support_staff|null, departure_kind, departure_datetime ('' if none), include_equipment_truck|null } }`. Cover: plain sentences,
   aliases (WMU, Bobcats, "Miami Ohio", "UB"), word numbers ("seventy players"), missing counts (null), "no truck", weekday
   constraints ("can't leave before 2 PM Friday" → not_before 2026-11-27T14:00 for G10), "must leave by 9am the day before" →
   not_after, a home game (Toledo → game_id null), an unknown opponent, typos ("Buffallo"), extra noise, and bullet-list style.
   Starter examples:
   - `"Ohio trip: 68 players, 12 coaches, 11 support staff, bring the equipment truck, can't leave before 2 PM Friday"`
     → G10, 68, 12, 11, not_before, 2026-11-27T14:00, true
   - `"Buffalo — seventy players, 12 coaches, 12 staff. No equipment truck."` → G12, 70, 12, 12, none, '', false
   - `"WMU game, 64 athletes and 11 coaches"` → G04, 64, 11, null, none, '', null
   - `"Toledo trip for 70 players"` → null game (home), 70, null, null, none, '', null
2. `tests/accuracy/score.ts` (pure): `scoreCase(expected, draft)` → per-field correct/incorrect; `aggregate()` → report numbers.
   Unit test it in `tests/accuracy/score.test.ts` (`vitest.config.ts` already includes `tests/**/*.test.ts`).
3. `tests/accuracy/run.ts`: flags `--limit N`, `--base URL` (default `http://localhost:3000`), `--skip-recommend`.
   - **Sequential** requests with a 500 ms gap. On 429 / `ai_busy`, back off (`retry_after_ms` or 2^n s), max 3 tries.
     Stop the run with a clear message on `ai_credits_empty`.
   - Send `X-Role: staff`. Read `/health` → `mock` = (ai_mode === 'mock').
   - Recommendation check: for TRIP-G12 (and G10 if it has packages) call recommend ×3 → valid id rate = recommended id ∈
     feasible package ids; fact_guard_pass_rate = share with `fact_guard.passed && !replaced` (counting parse-free prose only).
   - Write `results/latest.json` plus `results/run-<timestamp>.json`, and print a table (field → accuracy).
4. Commit a mock-mode `latest.json` now (labeled `mock: true`). Track C replaces it with a real run at checkpoint 3.
