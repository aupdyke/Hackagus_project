# A-06 · Reliability: input hardening, AI-failure fallbacks, L1 server tests
**Track:** A · **Level:** L1 · **Estimate:** 60 min · **Branch:** `track-a`
**Depends on:** A-03 (real packages), A-05 (optional; test whatever exists)

> Read `CLAUDE.md`. "Reliability & data handling" is worth 15 pts: bad input, API errors, human review, no invented facts.

## Context
- Express app factory: `createApp()` in `apps/server/src/app.ts`. When `VITEST` is set, the DB is in-memory (`db.ts`).
  Seed with `seedIfEmpty(computeTripPackages, true)` from `repo.ts` / `features/planner.ts`.
- Errors: every error is `{ error: { code, message, retryable, request_id? } }` (`http.ts` `errorMiddleware`).
  The `on()` helper validates bodies with the shared Zod schemas.
- AI errors (`AiError` codes): ai_busy (429), ai_credits_empty (402), ai_spend_limit, ai_unavailable, ai_bad_output,
  ai_auth, ai_request_invalid. Friendly copy: `FRIENDLY_ERROR` (shared `errors.ts`).
- Parse (`features/parse.ts`) already falls back to `fallbackParse` with a notice on any `AiError`.

## Steps
1. Test helper `apps/server/src/test/server.ts`: `startTestServer()` → `{ url, close }` (app.listen(0)), resetting and
   seeding the DB first. Use global `fetch`.
2. Hardening in `routes/trips.ts` `submitRequest`:
   - players ≤ number of eligible players (else 400 "Only N players are travel-eligible").
   - `not_before`/`not_after` datetime must fall within 3 days before the game and ≤ the kickoff (else 400).
   - excluded hotel ids must exist in that city (else 400).
3. Make sure every `AiError` reaching `errorMiddleware` includes `request_id`, and that 429 → `retryable: true`.
4. Tests (`apps/server/src/routes/l1.test.ts`):
   - health; list trips (6 away trips); parse (mock) → G10 + no missing fields for the demo sentence below.
   - parse when the AI throws `ai_credits_empty` (use `vi.spyOn` on the client module, or `vi.mock('../aivana/client')`) →
     200, `source: 'fallback'`, notice mentions credits.
   - submitRequest errors: home game, mismatched game_id, constraint without datetime, players 0 and 200, malformed JSON
     → 400 with the error shape; unknown trip → 404; `X-Role: athlete` on /trips → 403.
   - happy path: submit G10 → 3 packages → select B → approve → status approved.
   - recommend when AI throws → 200, `source: 'template'` (once A-05 lands; mark `it.skip` with a TODO otherwise).
   - Demo sentence: `"Ohio trip: 68 players, 12 coaches, 11 support staff, bring the equipment truck, can't leave before 2 PM Friday"`.
